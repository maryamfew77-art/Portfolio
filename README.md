# Personal Portfolio

A modern, responsive personal portfolio website showcasing my skills, projects, experience, and contact information as a Software Engineering student and aspiring Frontend Developer.

## ✨ Features

* Responsive design for desktop, tablet, and mobile
* Mobile hamburger navigation
* Hero, About, Skills, Projects, and Contact sections
* Project screenshots with GitHub links
* Direct LinkedIn, GitHub, and email links
* Smooth and clean modern UI
* Peach and pink gradient background
* Responsive project grid

## 🛠️ Technologies

* HTML5
* CSS3
* Responsive Web Design

## 📂 Projects Featured

* **Learning Dashboard** — HTML, CSS, JavaScript
* **Movie Explorer** — Next.js, React, API
* **AI Opportunity Navigator** — Next.js, TypeScript, API, Tailwind CSS

More projects are available on my GitHub repositories.
